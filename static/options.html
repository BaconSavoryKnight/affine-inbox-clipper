AFFiNE Inbox Clipper

Clips go into one AFFiNE sidebar folder (your Inbox) so they stay separate from notes you've already sorted.

1. Connect

Sign in to AFFiNE in a normal Firefox tab first — the clipper uses that login. Nothing is stored except the settings on this page.

2. Choose the Inbox

3. Clip defaults

Shortcuts

Alt+Shift+C opens the clipper. Alt+Shift+A quick-clips the page (or your selection) with the defaults. Right-click a page, selection or link for “Clip to AFFiNE Inbox”. Change keys in about:addons → ⚙ → Manage Extension Shortcuts.
